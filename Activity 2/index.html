Deadlock Avoidance: Banker's Algorithm

Avoidance grants a request only if the system stays in a safe state afterwards. It looks ahead; it does not look for deadlocks that already exist.

Unsafe is not deadlocked. An unsafe state only means that no order is guaranteed to let every process finish. Processes may still finish if others release resources early. A deadlock means processes are already blocked for good.

Deadlock Detection

Detection inspects the current allocation and requests and reports which processes can never proceed. Unlike the Banker's algorithm, it takes no part in granting requests.

Cycle versus deadlock. With single-instance resources, a cycle in the resource-allocation graph is a deadlock. With multiple instances a cycle is only a potential circular wait, so the matrix detection algorithm decides.
